# Wither Away

A simple NeoForge mod for Minecraft 1.21.1 that gives you full control over Wither-related sounds and effects.

## Features
- **Mute Global Spawn Screech:** Silences the world-wide sound played when a Wither is summoned.
- **Mute All Other Wither Sounds:** Comprehensively silences ambient, hurt, death, skull launches, and all Wither-specific explosions (including the spawn explosion).
- **Disable Boss Bar:** Optionally hide the purple boss bar at the top of the screen.
- **Disable Screen Darkening:** Prevents the sky and screen from darkening when a Wither is nearby.

## Configuration
All options are fully configurable via the mod's config file or in-game menu. 

## Supported Languages
- English (US)
